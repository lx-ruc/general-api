# 火山引擎公有云部署申请指南（慧沐引擎 token 中转站）

> 目的：把本项目部署到火山引擎公有云对外提供服务。本文给出资源申购物单（规格/数量/计费方式）、账号与备案前置流程、网络规划与部署落地步骤。
> 规格依据：本仓库 `docs/高并发设计.md` 压测结论 —— 目标负载 20~100 RPS 稳态、几百路 SSE 并发长连接，单机完整链路实测 2161 RPS（20 倍余量），**计算不是瓶颈，可用性才是**；瓶颈在上游厂商限流，已由协调器消化。

## 一、部署形态选型

```
客户 ──▶ ALB（HTTPS:443 终止 TLS，轮询 + /healthz 健康检查）
          ├── ECS 网关 A（跨可用区）──┐
          ├── ECS 网关 B            ──┼──▶ 托管 Redis（协调器全局共享，可选）
          └──                        ──┴──▶ 云数据库 PostgreSQL（主备，内网）
ECS 出口走各自 EIP：调上游厂商 API（DeepSeek/智谱/通义）+ SMTP 发信
```

- 网关无状态（state 全在 DB + Redis），双实例跨可用区，任一台宕机 ALB 自动摘流
- TLS 终止在 ALB，替代现在 compose 里的 Caddy 角色；SSE 透传注意事项见第五节
- **最小试点方案**（先跑通再升配）：1×ECS 跑 `deploy/docker-compose.yml` 全套（自建 PG/Redis 容器）+ 1 个 EIP。省事但有单点，只适合内部验证，本文以下按生产方案申购

## 三、账号与前置流程（按顺序）

1. **注册火山引擎账号** → 完成**企业实名认证**（营业执照、法人信息；对外售卖计费服务建议企业主体，影响备案主体与开票）
2. **域名**：已有域名可直接用；没有则在火山引擎/任意注册商购买（.com 年费几十元）
3. **ICP 备案**（关键路径，最长）：大陆地域对域名提供 80/443 Web 服务**必须先完成备案**，火山引擎备案系统提交，周期约 **1~3 周**。资源开通可与备案并行，但备案下来前域名无法对外提供服务
   - 免备案替代：火山引擎国际站/海外地域，但大陆客户访问延迟差，不建议
4. **开通产品**：控制台开通上表 7 项产品（开通免费，按实例计费）
5. **申购/下单**：按第二节购物单创建资源；先 1 台 ECS 跑通部署，再补第 2 台
6. （对外售卖如客户要求）**等保二级**备案可作为后续合规项，首期不阻塞

## 四、网络与安全规划

**VPC**：用默认 VPC 或自建（网段如 10.0.0.0/16），ECS / RDS / Redis 全部放同一 VPC 内网互通；地域选离主要客户近的（华北-北京 / 华东-上海 / 华南-广州）。

**安全组规则**（最小开放原则）：

| 对象 | 方向 | 端口 | 源 | 说明 |
|------|------|------|-----|------|
| ECS | 入 | 22 | 运维固定 IP | SSH 运维，禁止 0.0.0.0/0 |
| ECS | 入 | 8080 | 仅 ALB 安全组 | 网关只接受 ALB 转发 |
| ALB | 入 | 80/443 | 0.0.0.0/0 | 对外入口 |
| RDS | 入 | 5432 | 仅 ECS 安全组 | 内网访问，不开公网 |
| Redis | 入 | 6379 | 仅 ECS 安全组 | 同上 |
| ECS | 出 | 全部 | 0.0.0.0/0 | 调上游厂商 API（443）+ SMTP（465/587） |

`/metrics` 不要对公网裸开；确需外部抓取时用配置项 `security.metrics_token` 加鉴权（本项目已支持）。

## 五、部署落地（对应仓库已有物料）

1. **构建与分发**：本机 `make cross-build` 产出 `dist/token-gateway`（linux/amd64 单二进制，前端已内嵌），scp 到两台 ECS `/opt/token-gateway/`，配 `config.yaml`（从 `config.example.yaml` 复制，改 `jwt_secret`）
2. **systemd 托管**：安装 `deploy/token-gateway.service`（`LimitNOFILE=65535` 是几百路 SSE 的硬需求，unit 里已带；`Restart=always` 保活）
3. **接 RDS**：`TG_DATABASE_DRIVER=postgres` + `TG_DATABASE_DSN=host=<RDS内网地址> ... sslmode=disable`（或写进 config.yaml）；本地已有 SQLite 存量数据用 `-migrate-from-sqlite` 一次性搬入
4. **接 Redis**：`TG_REDIS_ADDR=<托管Redis内网地址>:6379` + `TG_REDIS_PASSWORD=<密码>`；连不上自动 fail-open 回退进程内存，不会拖死数据面
5. **ALB 配置要点（SSE 红线）**：
   - 健康检查：路径 `/healthz`，间隔 5s，超时 2s（与仓库 Caddyfile 参数一致）
   - **空闲/读写超时调大到 ≥300s**：推理型模型首 token 可能超过默认 60s，超时过短会把长请求拦腰切断
   - 如产品侧有响应缓冲/聚合类开关，确认关闭，保证流式逐块透传
   - 代码侧无需改动：`http.Server` 不设 `WriteTimeout`、上游 client 只设 `ResponseHeaderTimeout`，均已是既定红线
6. **备份**：RDS 控制台开自动备份（每日全量 + 保留 7 天）为主；`deploy/backup.sh` 挂 cron（`0 4 * * *`）做 `pg_dump` 第二份，**建议管道直传 TOS 而非落本地盘**（DB 按月归档会涨到几十 GiB，7 份压缩 dump 挤爆 40 GiB 系统盘）。裸镜像需先 `apt install -y postgresql-client-16 cron`
7. **监控**：云监控盯 ECS CPU/内存、RDS 连接数/磁盘、ALB 5xx；网关侧 `/metrics` 有请求量、延迟直方、活跃 SSE 流、上游 429、Key 冷却、结算失败等专项指标
8. **上线验证**：按 `docs/全流程测试文档.md` 走端到端；`tools/e2e/run.py` 可对测试环境回归
9. **管理员初始化**：`bootstrap_admin_*` 配置建首个系统管理员，登录管理台配渠道/定价/额度
