**关键结论**

1. **限流主体分三类**：DeepSeek 几乎不限（500+ rps 无 429）；通义不限流但思考系 p50 5–10s，延迟即上限；Kimi/智谱是硬并发墙。智谱为**账户级**（1302），同账户多 Key 不能扩容（双 Key 30+30 只过 51），扩容只能不同账户、升权益等级（V0~V3，积分=消费额 1:1）或控制台提额申请。官方机制与各模型实测已写入模型备注（平台管理台可见）。
2. **429 风暴的自愈**：上游 429 触发网关侧 key/渠道冷却 60s（429 不进熔断计数），期间后续请求被网关毫秒级拒绝（`upstream_busy`）——这是保护不是故障；压测同渠道必须间隔 ≥70s。
3. **网关自身**：拒绝路径（鉴权+预检全走）扛 2212–5335 rps、p50 1–10ms；默认 per_key_rpm=60 是真实业务的第一个限流闸门，大客户单独调额。
